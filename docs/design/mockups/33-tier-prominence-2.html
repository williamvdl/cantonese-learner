MOCK-33 — tier prominence, second pass

Four more, all built on the same correction: the tier and the link to the next tier stay next to each other instead of being pushed to opposite edges. What differs is where the pair sits and how much surface it gets.

The pair, above the title

The whole row moves above the lesson name and groups left, so it reads as one unit before the title rather than a footnote after it. Tier number at body size in ink, the move immediately beside it. Nothing sits at the far right edge any more.

MOCK-33-F
The tier run
