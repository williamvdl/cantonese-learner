Part 2 · The bottom tab bar, which shares the line

The design system treats the Learn/Chat/Quiz switch and the bottom tab bar as one component with one emphasis language: a brand line on the edge nearest the content. So the line weight changes on both or on neither. Only the line changes here; the bar's labels stay as they are. At 3px the bar is 1px taller, so the --tabbar-h token, which six rules use to keep content clear of the bar, goes from 46px to 47px in the same change.

Part 3 · Everywhere else the label appears

The small capitalised label is one family of three classes with identical metrics: 10.5px, medium weight, 0.12em tracking, uppercase. Brand orange as .eyebrow, grey as .section-label, and .lesson-note-title, a hand copy of .eyebrow. The label toggle resizes all of them, as it would in the app.
