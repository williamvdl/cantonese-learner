What this screen needed most

Quiz is the most inline-styled screen in the app — 20 style="…" injections across the two render paths, mostly threading a per-topic color through buttons, borders and toggles. That's the category-accent system you'd already decided to switch off, still fully wired here. Everything below is class-driven; no colour is passed in as an argument.

It also had two colours doing double duty: #27AE60 and #E74C3C were hardcoded for correct/wrong in the review list — but those are tone 4 and tone 1, and they appear as tone colours in the jyutping inside the same card. Same colour, two unrelated meanings, inches apart.

The one decision I'd flag

There's no red. Correct is jade; the wrong choice greys out, strikes through and takes an ✕, while the right answer lights green beside it. Adding a proper error red would make it a fourth semantic colour in a palette that already carries brand orange, Oxblood and jade — and any red close enough to read as "error" sits uncomfortably near both of the first two. The miss is still unmistakable, and it's less punitive. If you'd rather have the red, it's one token and I'll add it.

Other changes

  • Result screen loses the emoji (🏆 / ⭐ / 💪) for a score ring — the ring reuses the same arc mechanic as the checkpoint diamond, so the two "progress" ideas in the app share one visual language.
  • Score moved into the context row alongside question count, so the quiz body holds only the question.
  • The teaching panel is neutral-bordered, not red, and leads with the correct answer rather than the error — the point of the panel is the thing to learn.
  • Choices are one card style — the same primitive as everywhere else, with the mark circle carrying state rather than the whole card changing shape.
  • "Next" is the only filled button in the flow. Same reasoning as "Next up" on the path: one clear action gets the fill, everything else is a ghost.

Worth your eye

  • The direction toggle labels (漢→EN, EN→漢, 🔊→EN) are inherited as-is. They're compact but cryptic; worth deciding whether they should be words on a settings row instead of a permanent three-way toggle above every question.
